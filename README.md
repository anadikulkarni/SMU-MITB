# SMU-MITB

My preparation for SMU's MITB (Data Science & Analytics) programme.

**Start here: [COURSE.md](COURSE.md).** It's a self-paced, 60-day course with 12 modules covering Python, pandas, statistics, SQL and data modelling, linear algebra, Excel decision modelling and machine learning, built around *Python for Data Analysis* and *Hands-On Machine Learning*, with *Fluent Python* for deeper Python.

| Folder | What's in it |
|---|---|
| `checkpoints/phase1/` | The Phase 1 Python exam: fill in `exercises.py`, then run `pytest checkpoints/phase1 -q` |
| `checkpoints/module5/` | `make_messy_sales.py` generates the Module 5 messy-CSV checkpoint and its answer key |
| `work/` | My notebooks and scripts, one folder per module |
| `notes/` | My session log and concept write-ups |
| `data/` | Downloaded datasets (Git ignores this folder) |
